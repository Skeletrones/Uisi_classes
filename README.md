# Пары — расписание УрТИСИ

Мобильное расписание, которое не заставляет скроллить огромную Excel-таблицу. Загружаешь
XLSX УрТИСИ — приложение само разбирает недели, дни, пары, подгруппы, преподавателей и
аудитории. Всё хранится на телефоне, без сервера и регистрации.

Есть две версии:

- **Android APK** — обычное приложение для телефона, работает офлайн;
- **PWA** — та же версия в браузере, можно добавить на главный экран.

## Что умеет

- Разбирает XLSX-расписание УрТИСИ: даты недель, пары, типы занятий, подгруппы `1 п/гр` /
  `2 п/гр`, преподавателей с должностями, аудитории и корпуса `УК №…`.
- Показывает только пары выбранной подгруппы, общие пары помечает как «общая».
- Кнопка «Фильтры»: подгруппа и преподаватель проекта. Список преподавателей берётся из
  таблицы, чужие пары проекта скрываются.
- Календарь умеет фильтровать по типу занятия (лекции / практики / лабы / проект),
  подгруппе и своей группе проекта. Поиск по предметам — мультивыбор: выбери несколько,
  отметки останутся только на днях, где есть эти пары.
- Личные дела: вождение, секции, встречи. Добавляются поверх расписания по времени, не
  меняют XLSX и подсвечиваются как «во время пары», если попали на занятие.
- Воскресенье показывается как отдельный день без пар: с субботы свайп сразу на
  понедельник, а с открытого воскресенья — в любую сторону. Вернуться помогает кнопка
  «К сегодняшнему дню» или календарь.
- Автопереход: через настраиваемое время после последней пары (по умолчанию 30 минут)
  открывается следующий день. В воскресенье сразу открывается понедельник.
- Прячет пустые окна в начале и конце дня; окна внутри дня показывает штриховкой и
  подсказывает, у какой подгруппы в это время пара.
- Автоматически включает сокращённое предпраздничное время (например, 3 ноября перед
  4 ноября) и правильную сетку для субботы.
- Чётность недели считается от начала учебного года, а не от первой недели файла — можно
  загружать обрезанные расписания на пару недель.
- Свайпы влево/вправо и стрелки на клавиатуре для перехода по дням. На планшете и
  компьютере в горизонтальной ориентации календарь всегда открыт сбоку — сторону можно
  переключать кнопкой «Слева / Справа».
- Тёмная, светлая и системная тема; настраиваемые цвета типов пар (пипетка и HEX);
  компактный режим; настройка окон, обеда, текущей пары.
- Импорт XLSX и JSON, экспорт JSON, удаление данных.
- Полностью офлайн после установки; данные не уходят в сеть.

## Быстрый старт

Нужен Node.js 20+.

```bash
cd schedule-app
npm install
npm run dev
```

Открой `http://localhost:5173` (или адрес из вывода Vite — он доступен и с телефона в той же
Wi-Fi).

Сборка веб-версии:

```bash
npm run build
npm run preview
```

## PWA на iPhone и GitHub Pages

Веб-версию можно открыть на iPhone через Safari и поставить на домашний экран — она будет
запускаться без адресной строки и работать офлайн.

Важно: в репозиторий кладётся **содержимое папки `schedule-app`**, а не папка целиком.
То есть `package.json` и `.github/workflows/deploy.yml` должны лежать в корне репозитория.

### Первый раз, через GitHub Desktop

1. Установи [GitHub Desktop](https://desktop.github.com/) и войди в аккаунт GitHub
   (аккаунт можно создать там же).
2. **File → Add local repository** → выбери `A:\neiroslopsfeed\schedule-app`. Если GitHub
   Desktop скажет, что это не репозиторий, нажми ссылку **create a repository**:
   - Name: `pary-urtisi` (любое);
   - Local path: `A:\neiroslopsfeed\schedule-app`;
   - Git ignore: не создавать (файл `.gitignore` уже есть);
   - License: None.
3. Нажми **Create repository**, затем **Commit to main** (сообщение можно оставить
   `v0.4.0`).
4. Нажми **Publish repository**. Если хочешь бесплатный GitHub Pages — сними галочку
   **Keep this code private** (публичный репозиторий).
5. Открой репозиторий на github.com → **Settings → Pages** → **Build and deployment** →
   **Source: GitHub Actions**.
6. Открой вкладку **Actions** и дождись зелёной галочки у workflow
   **Deploy PWA to GitHub Pages** (после пуша он запускается сам).
7. Адрес появится там же в **Settings → Pages**: `https://<логин>.github.io/<репозиторий>/`.

### Первый раз, через командную строку

Установи [Git for Windows](https://git-scm.com/download/win), затем в PowerShell:

```powershell
cd A:\neiroslopsfeed\schedule-app
git init
git add .
git commit -m "v0.4.0"
git branch -M main
```

Создай на github.com пустой репозиторий (без README), скопируй его адрес и выполни:

```powershell
git remote add origin https://github.com/<логин>/<репозиторий>.git
git push -u origin main
```

Дальше — те же пункты 5–7: **Settings → Pages → Source: GitHub Actions**, дождаться
workflow и открыть адрес.

### Установка на iPhone

1. Открой адрес `https://<логин>.github.io/<репозиторий>/` в **Safari**.
2. Нажми **Поделиться → На экран «Домой»**.
3. Запусти приложение с иконки и загрузи XLSX — файл сохранится на устройстве.

Важно: ставится именно Safari (Chrome на iOS не умеет «На экран Домой»). Для проекта
используется относительный `base: './'` и `.nojekyll`, поэтому он работает и в подпапке
`/<репозиторий>/`. Первый запуск требует интернета, дальше — офлайн.

Локальная проверка production-сборки:

```bash
npm run build
npm run preview
```

## Android APK

Проект уже обёрнут в Capacitor, нативная папка `android/` лежит рядом.

Что нужно:

- JDK 21;
- Android SDK с platform 35 и build-tools 35;
- переменная `ANDROID_HOME` (или `android/local.properties` с `sdk.dir`).

Сборка debug-APK одной командой:

```bash
npm run android:debug
```

Готовый файл:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

Удобная копия для раздачи уже лежит здесь:

```text
apk/Pary-UrTISI-0.4.0.apk
apk/ЧТО-НОВОГО-0.4.0.txt
apk/КАК-УСТАНОВИТЬ.txt
```

Версии не перезаписывают друг друга: старый `apk/Pary-UrTISI.apk` (0.3.0)
остаётся на месте, новая сборка лежит рядом с версией в имени файла.

Можно скинуть APK на телефон, открыть и разрешить установку из неизвестных источников.
Debug-подпись подходит для установки и раздачи друзьям, но не для Google Play.

Если нужно просто обновить веб-часть в уже собранном Android-проекте:

```bash
npm run android:sync
```

Открыть проект в Android Studio:

```bash
npm run android:open
```

Иконки и splash-экраны:

```bash
npm run icons
```

Иконки генерируются из `public/pwa-512.png` в `android/app/src/main/res/`.

## Конвертер для ПК

Если удобнее получить JSON на компьютере:

```bash
npm run convert -- "C:\path\to\расписание.xlsx"
npm run convert -- "расписание.xlsx" -o schedule.json
```

Рядом с файлом появится `.json`. Его можно импортировать в приложение кнопкой
«Загрузить .xlsx» — она принимает и JSON.

## Как обновить расписание

1. Скачай новый XLSX с сайта вуза.
2. В приложении нажми кнопку загрузки в шапке (или «Обновить файл» в настройках).
3. Выбери файл — приложение покажет предпросмотр: группа, период, количество недель, дней и
   пар. Если что-то не распозналось, будет список предупреждений.
4. Нажми «Открыть расписание».

```text
src/lib/times.ts       сетки времени, предпраздничные дни
src/lib/holidays.ts    праздники РФ
src/components/        экраны и карточки
src/hooks/             useNow, useTheme, usePersistentState, useMediaQuery
tools/convert.ts       конвертер XLSX → JSON для ПК
tools/make-icons.mjs   PWA-иконки
tools/make-android-assets.mjs  иконки и splash для Android
.github/workflows/     деплой PWA на GitHub Pages
android/               нативный проект Capacitor
samples/               пример расписания ИТ-52б
```

## Приватность

Файл читается локально в браузере/WebView. Расписание и настройки лежат в `localStorage`
устройства. Никаких запросов с данными расписания нет.
